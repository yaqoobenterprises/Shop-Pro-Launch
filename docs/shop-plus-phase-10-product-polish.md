# Shop Plus — Phase 10 product polish

## Implemented
- Transactions: exact nonnegative inclusive amount bounds (up to two decimal places, safe integer minor units), explicit newest/oldest/highest/lowest sorting, stable ID tie-break, identical filters on primary cloud query, fallback cloud query, local queue, pagination and full CSV export. Cloud query explicitly scoped to current organization, authoritative count cannot silently become zero. Filters persist in current authenticated workspace memory, reset clears them. CSV includes account name and exact decimal strings; no transaction entry parser or stored data changed.
- Overview: on-demand cloud-only comparison against immediately preceding inclusive business-date window of equal length (not calendar-month comparison), with exact income, expenses and operating result values; five latest recorded active transactions within selected period. Selected-period drilldown into Transactions. Both reads independent so failures do not masquerade as zero; no comparison on incomplete local/demo sources. Initial page does not fetch comparison history automatically.
- Accounts: on-demand, paginated authoritative account posting history (including inactive accounts, transfer references, reversals, opening movements and historical running balances). Reads only, current organization scope, stale request protection, separate unavailable/empty states. Not a complete cross-account transfer register; no reactivation or accounting policy change. Account picker lists up to 1000 accounts.
- Branding: replaced 192/512 PNG PWA icons with Shop Plus mark, refreshed static service worker shell to cache current branding. Historical IndexedDB, localStorage and event identifiers retained for backward compatibility. Old shell cache cleanup uses existing legacy prefixes; no financial cache or queued work deleted. No forced service worker activation.
- Excel: rejects monetary values outside 15-digit minor-unit safety bound; exact CSV alternative. Report and transaction detail display stored fractional amounts. No currency conversion.
- Performance: compare/history are opt-in, avoid new initial data requests, new helpers use existing dependencies. Final comparative lab and installed-PWA verification remain outstanding.
